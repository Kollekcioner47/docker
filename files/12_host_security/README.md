# Готовые файлы к практике 12

Каталог про безопасность хоста и аудит. Скриптов здесь нет намеренно:
все команды практики студент набирает сам, а в этом каталоге лежит
только то, что является предметом изучения.

| Файл | Что это |
|---|---|
| `audit/docker.rules` | Правила `auditd` для хоста с Docker: наблюдение за настройками демона, сокетом, бинарниками и данными |
| `checklist.md` | Чек-лист эксплуатации: 11 пунктов «что проверить на машине с Docker» со ссылками на практики |
| `README.md` | Этот файл |

## audit/docker.rules

Файл копируется в `/etc/audit/rules.d/99-docker.rules` и подхватывается
командой `sudo augenrules --load`. Имя начинается с `99` не случайно:
`augenrules` складывает все файлы каталога в один по алфавиту, и наши
правила должны идти последними, чтобы не затирать системные.

У каждого правила наблюдения есть ключ `-k` — имя, по которому событие
потом ищут командой `ausearch`. Правило без ключа бесполезно: событие
в журнал попадёт, а найти его будет нечем.

Разбор правил и работа с журналом — в практике 12, шаг 7.

## checklist.md

Список того, что стоит проверить на машине с Docker, с пояснением
«почему» и ссылкой на практику, где это разбирается. Это не требования
аудита, а сводка курса: каждый пункт обоснован конкретным разбором.

Часть пунктов для учебного стенда можно сознательно пропустить —
например, `userns-remap`. Пропустить осознанно — не то же самое,
что не знать о нём.
